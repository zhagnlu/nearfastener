# 本地多语言文案

支持英语（`en`）、简体中文（`zh-CN`）、西班牙语（`es`）、法语（`fr`）、德语（`de`）、葡萄牙语（`pt`）、俄语（`ru`）、阿拉伯语（`ar`）和日语（`ja`）。

每个 JSON 文件使用英文原文作为键，译文作为值，覆盖 全部页面的正文、导航、页脚、图片说明、输入提示、动态表单反馈和页面标题/描述。`en.json` 是完整原文目录；`invariants.json` 明确列出各语言保持原样的标准编号、材料牌号、尺寸、品牌和联系方式。

## 修改文案

1. 直接编辑相应语言的 JSON 值。保持键不变，不要在译文中添加 HTML。
2. 新增英文文案时，同步在 `en.json` 和其他八份语言文件中增加相同的键。修改英文原文时也应同步更新所有文件中的键。
3. 执行 `npm run i18n:build` 校验词典，执行 `npm run export:static` 生成九种语言的独立 HTML。应用的 `dev` 和 `build` 命令也会自动校验词典。
4. 执行 `npm run test:i18n` 检查全站文案覆盖、键一致性、技术标识保留及生成文件与源文件的一致性。

文案只在构建或服务端渲染时使用，浏览器不下载完整词典，也不扫描和翻译 DOM。各语言页面的正文、导航、图片说明、输入提示和元数据直接输出为对应语言的 HTML。表单交互需要的少量提示已随页面以隐藏 HTML 输出。

所有语言都有独立路径，英语为 `/en/`，简体中文为 `/zh-cn/`。语言菜单是普通链接，切换时跳转同页的其他语言版本；URL 决定语言，不读取浏览器已保存偏好。JavaScript 可用时保留查询参数与锚点；禁用 JavaScript 时正文和语言菜单仍可使用。旧地址兼容方式见 [多语言页面](../../docs/i18n/language-pages.md)。

阿拉伯语使用 `dir="rtl"`。输入值、上传文件名、HTML 结构和技术数值不参与翻译。浏览器原生的必填/邮箱格式校验提示语言由浏览器设置决定。自定义文件验证提示使用所选网站语言。

Resources 的九篇文章已补齐正文，并覆盖全部九种语言。文章原文在 `content/resources.json` 维护；新增章节、摘要及表格文字后，应同步补齐语言文件。语言模块只显示已有译文，不生成技术文章或资质信息。
