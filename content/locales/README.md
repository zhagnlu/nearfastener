# 本地多语言文案

支持英语（`en`）、简体中文（`zh-CN`）、西班牙语（`es`）、法语（`fr`）、德语（`de`）、葡萄牙语（`pt`）、俄语（`ru`）、阿拉伯语（`ar`）和日语（`ja`）。

每个 JSON 文件使用英文原文作为键，译文作为值，覆盖 49 个页面的正文、导航、页脚、图片说明、输入提示、动态表单反馈和页面标题/描述。`en.json` 是完整原文目录；`invariants.json` 明确列出各语言保持原样的标准编号、材料牌号、尺寸、品牌和联系方式。

## 修改文案

1. 直接编辑相应语言的 JSON 值。保持键不变，不要在译文中添加 HTML。
2. 新增英文文案时，同步在 `en.json` 和其他八份语言文件中增加相同的键。修改英文原文时也应同步更新所有文件中的键。
3. 执行 `npm run i18n:build` 生成 `public/locales/*.js`，或执行 `npm run export:static` 同时更新词库与静态网站。应用的 `dev` 和 `build` 命令也会自动生成词库。
4. 执行 `npm run test:i18n` 检查全站文案覆盖、键一致性、技术标识保留及生成文件与源文件的一致性。

浏览器通过同站点的脚本文件按需加载所选语言，第一次加载后保留在当前页面内存中。采用脚本包装而非 `fetch`，因此直接打开 `static-site/index.html` 时也能从磁盘读取语言文件，不需要网络或翻译服务。HTTP 访问时仍需要先取得对应本地站点文件，这不是离线缓存整个网站的 PWA。

英语是默认语言。切换后使用 `localStorage` 记忆偏好，并为站内链接附带 `?lang=zh-CN` 等参数。查询参数优先于已保存偏好。存储不可用时仍可切换语言并通过链接保留选择。加载失败会保留上一语言并显示重试提示；快速连续切换只应用最后一次选择。

阿拉伯语使用 `dir="rtl"`。输入值、上传文件名、HTML 结构和技术数值不参与翻译。浏览器原生的必填/邮箱格式校验提示语言由浏览器设置决定。自定义文件验证提示使用所选网站语言。

原站尚未补全的文章正文占位说明已如实翻译；语言模块不会生成新的技术文章或资质信息。译文可在上述文件中继续校订。
