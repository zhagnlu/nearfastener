ISO 10642:2026

Hexagon socket countersunk head screws with reduced loadability.

Standard scope

The standard covers steel and stainless steel screws with metric coarse threads from M2 to M20.

Reduced loadability

The countersunk head and socket geometry reduce loadability. Check the specified property class and the application requirements.

DIN 7991 reference

DIN 7991 is a withdrawn reference. Verify dimensions and application suitability before substituting ISO 10642.
